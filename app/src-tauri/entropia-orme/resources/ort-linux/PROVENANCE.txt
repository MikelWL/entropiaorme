Source: onnxruntime-webgpu 1.27.0, the official Microsoft ONNX Runtime
build for Linux x86_64 with the WebGPU execution provider (Dawn over
Vulkan) compiled in alongside the CPU provider. The platform counterpart
of the Windows onnxruntime-directml build bundled beside it in ../ort:
each platform ships one runtime carrying its GPU provider plus the CPU
fallback, and the session ladder in ocr_engine.rs prefers the GPU
provider with a CPU retry.

The library is published by the ONNX Runtime project on PyPI (the
onnxruntime-webgpu package is the official distribution channel for the
WebGPU-enabled native build; no GitHub release tarball carries it). The
shared library inside the wheel is a plain C-API runtime, independent of
the wheel's Python version tag.

Version skew against the Windows runtime (1.24.4) is deliberate: 1.27.0
is the first stable WebGPU-enabled Linux artefact, and the crate binding
requests C API version 24, which ONNX Runtime's API versioning contract
serves unchanged from newer runtimes. Requirements at run time: glibc
2.27+ and, for the GPU path, a Vulkan driver; with no usable adapter the
session falls back to the CPU provider.
